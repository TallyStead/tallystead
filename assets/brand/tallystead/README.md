# Tallystead logo kit

## Assets

- `tallystead-icon.svg` / `.png` — icon-only mark for app icons, favicons, avatars, and collapsed navigation.
- `tallystead-horizontal.svg` / `.png` — primary horizontal wordmark.
- `tallystead-lockup.svg` / `.png` — full logo with the tagline “Your household finances, under your roof.”
- Files ending in `-dark` are the matching versions for dark navy and similarly dark backgrounds.
- Browser favicons, Apple touch icons, and installable PWA icons are in `web-icons/`.

The SVG files are the production masters. PNG exports are convenience previews and should be regenerated at the size required by each platform.

## Palette

| Color | Hex | Use |
| --- | --- | --- |
| Deep navy | `#193A59` | House outline and “Tally” wordmark |
| Household green | `#237A61` | Ledger/check mark and “stead” wordmark |
| Soft mint | `#E1F3EC` | House interior |
| Warm off-white | `#F7F4EE` | Preferred light background |
| Slate | `#536477` | Tagline and supporting copy |
| Dark teal | `#234D5A` | House interior on dark backgrounds |
| Light slate | `#C8D4DC` | Tagline on dark backgrounds |

## Usage

- Keep clear space around the mark equal to at least one ledger-line thickness.
- Use the icon without the wordmark below 160 px of available horizontal space.
- Use the standard files on warm off-white, white, and other light backgrounds.
- Use the `-dark` files on deep navy, charcoal, and other dark backgrounds.
- Do not add currency symbols, gradients, shadows, or unapproved colors.
