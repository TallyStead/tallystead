# Security exceptions

Security scanners fail on unreviewed high/critical findings. The narrowly scoped exceptions below are consciously deferred, documented in source beside the relevant scanner suppression, and remain release gates where stated.

| ID | Finding and scope | Rationale and compensating controls | Owner | Review/expiry |
| --- | --- | --- | --- | --- |
| SE-001 | Package certificate verification is temporarily bypassed while building the API, backup, and Cloudflare-enabled Caddy images on this intercepted development network. | The environment cannot validate its intercepting CA. No household data is sent during builds; versions are reviewed and CI scans source/images. Install the household CA and remove every bypass instead of carrying it into a supported deployment. | Deployment owner | Review by 2026-09-14; expires before any production or internet-facing deployment. Release blocker. |
| SE-002 | Trivy DS-0002: API, backup tool, and Caddy currently start as root. | API reads Caddy's root certificate through its root-owned administration socket; it no longer rewrites live Caddy configuration. Caddy owns low-port/certificate volumes. The operator-only backup profile must read and replace database/object volumes managed by their official images. Only Caddy publishes application ports; its HTTP proxy ingress rejects sources outside the configured trusted proxy list. API/database/object services remain private, no service mounts the Docker socket, and backup scripts run only on explicit command. The web service uses the unprivileged `node` user. Remediation is a read-only certificate export path plus least-privilege container users. | Platform/security owner | Review by 2026-09-14; expires before Tallystead claims hardened internet-facing support. Local-network release may proceed with host access restricted. |

No other high-severity application, dependency, or privacy finding is knowingly deferred as of 2026-08-14. An exception added later must include a specific finding, affected path/version, exposure, compensating control, owner, approval date, and hard expiry.
